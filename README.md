# PepeGold

A simple static test page: original logo/tagline, stars, centered Pepe/planet/gold pile, and three native links. No page JavaScript, animation, dependencies, wallet or API.

Open `index.html` directly, or use Node.js 20+:

```sh
npm run build
npm run preview
```

On Windows use `npm.cmd`. Preview is `http://127.0.0.1:4173` (loopback only); `PORT` can override it. Build copies only HTML, CSS and the 10 referenced images into `dist/`.

Artwork uses existing optimized files unchanged. Link lettering uses system Impact/Arial Narrow fallbacks. Addresses and destinations are owner-supplied. Local checks and delivery state are in [CURRENT_BUILD.md](CURRENT_BUILD.md).
